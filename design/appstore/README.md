# App Store product-page header

`header-3840x1646.png` is an opaque RGB PNG for Apple's dedicated 21:9 product-page header placement. It matches the existing app icon and keeps its symbolic folding glyph and 001 badge inside the central crop-safe area. It is brand artwork, not a screenshot or a recorded opening count.

Created with the built-in image-generation tool and exported at the required pixel dimensions. Original generated files are retained outside the repository. See `prompts.txt` for the prompts.

Specifications: https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications
